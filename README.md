# 💼 Employee Salary Management System

A simple Python program to calculate an employee's final salary based on:

- Monthly Salary
- Leave Days
- Bonus
- Overtime Days

---

## 🚀 Features

✔️ Leave deduction calculation  
✔️ Bonus addition  
✔️ Overtime payment calculation  
✔️ Final salary display  
✔️ Clean and simple OOP structure  

---

## 🛠️ Technologies Used

- Python 3
- Object Oriented Programming (OOP)
